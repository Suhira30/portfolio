# Labor Link Image Setup

Please manually save your Labor Link screenshot as `assets/labor_link_preview.png`

The CSS has been updated to use this image as the background for the Labor Hiring project preview.

Alternatively, you can:
1. Take a screenshot from your Labor Link application
2. Save it as `labor_link_preview.png` 
3. Place it in the `assets` folder

The image will automatically appear as the background for the Labor Hiring System project card.
